# ☕ AI Café Finder & Assistant

## 📌 About

AI Café Finder & Assistant is a responsive web application that recommends cafés based on user preferences and provides a chatbot-style café assistant.

## ✨ Features

* 🤖 Café recommendations based on vibe and food preferences
* 💬 AI-style chatbot for café-related queries
* 📶 Wi-Fi, menu, parking and reservation responses
* 📱 Responsive and modern UI
* 🎨 Café-themed design with animations

## 🛠️ Technologies

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Recommendation and chatbot logic

## 📂 Project Structure

```text
AI-Cafe-Finder/
├── index.html

```

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html`.
3. Run it in any web browser or use VS Code Live Server.

## 🚀 Future Scope

* Real AI API integration
* Database for café information
* Google Maps/location support
* User login and reviews
* Real café reservations

This is currently a **front-end prototype**. The AI recommendations and chatbot responses are implemented using predefined JavaScript logic.
